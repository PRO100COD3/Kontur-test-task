# Kontur-test-task

## Описание
Данное приложение позволяет пользователю просматривать запуски ракет компании SpaceX.

---

## Функциональность

### **Главный экран**
- **Отображение данных о ракете**:
  - Высота.
  - Диаметр.
  - Масса.
  - Нагрузка.
- **Информация о запуске ракеты**:
  - Первый запуск.
  - Страна.
  - Стоимость запуска.
- **Информация о первой ступени**:
  - Количество двигателей.
  - Количество топлива.
  - Время сгорания.
- **Информация о второй ступени**:
  - Количество двигателей.
  - Количество топлива.
  - Время сгорания.
- **Кнопка настроек**
- **Кнопка просмотра запусков**

---

## Основные экраны

### 1. **Главый экран**
- **Описание**: Отображает основную информацию о ракетах.
- **UI-компоненты**:
  - UIImageView ракеты.
  - UIButton "Настройки".
  - UIPageControl для выбора ракеты.
  - UICollectionView горизонтального отображения характеристик ракеты.
  - UITableView отображения данныз ракеты.
  - UIButton перехода на экран запусков.

### 2. **Экран настроек**
- **Описание**: Экран настрое отображения данных.
- **UI-компоненты**:
  - 4 UISegmentedControl для выбора отображения данных.
 
### 3. **Экран запусков**
- **Описание**: Экран отображения о всех запусках выбраной ракеты.
- **UI-компоненты**:
  - UIImageView отображения успешности запуска.
  - UILabel отображения названия полета.
  - UILabel отображения даты.

---

## Дизайн
- Используется `UIKit` для построения интерфейса.
- Цвета и стили:
  - Фон: `Color.background` из Sketch.
  - Мягкие закругления для карточек и кнопок.

---

## Как работает приложение
1. При запуске загружаются данные через Moya.
2. Пользователь может:
   - Выбрать интерисующюю его ракету.
   - Настроить единицы отображения данных.
   - Нажать на кнопку информации о запусках.
   - Посмотреть успешность запусков.
